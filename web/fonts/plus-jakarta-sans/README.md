# Plus Jakarta Sans (self-hosted)

Latin 400 / 500 / 600 / 700 from [Fontsource Plus Jakarta Sans 5.3.0](https://fontsource.org/fonts/plus-jakarta-sans).

Vendored so `next build` (including Docker) does not fetch Google Fonts. Next.js 16 Turbopack currently 404s Plus Jakarta Sans v12 on `fonts.gstatic.com`.
