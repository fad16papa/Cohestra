# SPEC — Cinema Roll Motion System

## Why

Marketing Cinema rooms feel like static screenshots after room enter. Visitors need scroll-linked product-native progression.

## MUST SHOW

- Local chapter progress (0→1) driving semantic beats per room
- Clients: roster → Maya selected → relationship context
- Activities: overview → Golden Hour selected → operational state
- Follow-up: attention landscape → Due now focus → actionable person
- Analytics: overview → trend/follow-up effectiveness emphasis (2 beats)
- Cohestra AI: brief → evidence → recommended action (deterministic, not chat)
- Pill seek lands at room entry (~0.12), not midpoint
- Cross-room continuity via seed anchors (Maya, Golden Hour, due-now counts)

## MUST NOT

- Autoplay timers / setInterval choreography
- Per-mount scroll listeners
- Fake chat, typing, streaming theater
- Unsupported product capabilities
- Changes to Website Studio room behavior
- Epic 19 deployment work

## Motion doctrine

- Room enter: opacity + 10px translate ~300ms
- Selection: background/border ~200ms
- Panel reveal: crossfade / small translate ~320ms
- One major motion at a time; PRM snaps without transforms

## Success

Visitor describes experience as "Cohestra is doing something as I scroll" not "screenshots changing."
