# SPEC — Website Cinema Studio Proof

## Why

Visitors infer "nice demo website" instead of "Cohestra contains a real Website Studio."

## Capabilities (MUST SHOW)

- Website Studio identity (label, hostname, published state)
- Section structure rail from real seed sections
- Live Harbourline canvas via `SitePageRenderer` (unchanged visual)
- Selected-section inspector showing real field values
- Upcoming activities operational link (published activities → public site)
- Preview / Publish affordances (presentational, non-functional)

## MAY SHOW

- Mobile section chip strip when rails collapse

## MUST NOT CLAIM

- Live editing, autosave, or publish actions in cinema
- Studio sections not in Harbourline seed (carousel, FAQ, etc.)
- Cohestra AI, Clients, Activities room changes
- Manual data binding not supported by builder

## Success signal

Within 3–5 seconds a first-time visitor infers Cohestra contains a Website Studio where Harbourline's public site is authored.

## Constraints

- Website cinema room only
- Harbourline world locked
- Single-active-room mount preserved
- No Epic 19 / UAT changes
