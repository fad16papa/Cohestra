# Product brief — Website Builder mobile + desktop

## Problem

Operators edit their public homepage from phones and tablets, but the builder stacked the full editor above a tall preview — unusable on mobile and awkward on tablets.

## Goal

One builder that works on phone, tablet, and desktop without losing live preview fidelity.

## Success criteria

1. Mobile: toggle between Edit and Preview without scrolling through both
2. Tablet/desktop (≥1024px): editor and preview visible together
3. Phone preview scales to fit viewport width
4. Publish/Save remain reachable on small screens

## Non-goals

- Full mobile editing parity for every section field (use responsive forms, not separate mobile editor)
- Native app layout

## Metrics

- Qualitative: operator can complete edit → preview → publish on 375px viewport
- Reduced horizontal overflow / pinch-zoom on builder route
