# Press release

**Cohestra publishes a Document anyone can follow**

MANILA — Creativorare today opened a public Document on Cohestra that teaches operators how to run events in plain language.

Operators no longer have to guess the left menu or wait for a walkthrough. The Document sits next to Features on the landing page. It walks from “what is this?” to “publish a QR code” in numbered steps.

“If you can follow a recipe, you can follow this guide,” the page says. Guests still never need an account. They only need the link the operator shares.

# Internal FAQ

**Why not wait for Epic 19?**  
Teaching the product is a launch blocker for new operators. Hardening without a how-to leaves people stuck at sign-in.

**Why grade-school copy?**  
Operators are busy. Jargon (“dedup”, “tenant”, “handoff”) is how people quit. Plain words are the product.

**Maintenance?**  
When a menu label or plan limit changes, update `web/lib/marketing/product-docs-content.ts` in the same PR.
