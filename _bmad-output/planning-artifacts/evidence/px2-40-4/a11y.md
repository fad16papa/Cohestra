- One `main#main-content` on `/activities` and `/activities/{id}`

## Overlay (Story 38.6)

Draft archive dialog:

- Accessible name: `Archive this draft?`
- Description includes activity name
- Focus trap via existing `AlertDialog` + `trapOverlayTab`
- Escape closes when not archiving
- Cancel restores focus to Archive
- Confirm is destructive (`Archive draft` / `Archive anyway`)
- Failure keeps the dialog and the record; no optimistic vanish
- Protected 38.6 command-palette/campaign overlays still pass
