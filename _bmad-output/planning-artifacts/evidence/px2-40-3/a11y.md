## List

- One `main#main-content`, one document `h1` `Clients`.
- Semantic `<table>` / `<thead>` / `<tbody>` / `<tr>` / `<th scope="col">` / `<td>` at `md+`.
- No explicit `role="row"` or `role="columnheader"` on Clients.
- Axe `aria-required-children` / `aria-required-parent`: none on `/clients`.
- Serious/critical Axe: none on the 1440 populated Clients pass.
- Chips are 44×44+, wrap, and do not clip `Active` at 390/768/1024.
- Page overflow: none at 390/768/1024/1440.
- Sortable headers expose `aria-sort` on `th`.
- Row actions have names (`Mark {name} as contacted`, `Open WhatsApp for {name}`).
- Pagination Previous/Next have accessible names.

## Profile

- Populated `h1` is the client name.
- Loading / not-found / denied keep `h1` `Client`.
- Status is visible text via `LeadStatusBadge` + the lead-status select.
- Missing optional copy remains `Not provided` / `No notes yet`.
- WhatsApp/Viber confirmation: titled alertdialog, Escape closes, focus returns to the invoker.
- Expand/collapse uses `motion-local` 160ms; reduced motion computes `0s`.
- Profile actions use an explicit 45px floor so the 39.4 `>= 44` assertion stays honest.
