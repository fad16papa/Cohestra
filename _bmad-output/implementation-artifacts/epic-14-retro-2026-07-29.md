## What went well

- **Explicit story chain** — Legal gate → signup → checkout → shell → team → portal → jobs wired with forward deferrals documented.
- **14.4 CR caught production-risk issues** — Webhook retry ledger, open redirect, subscription status mapping, customer/tenant mismatch.
- **14.3 CR caught signup integrity issues** — verify-email JWT without OTP, slug-collision orphan user, nip.io redirect.
- **End-to-end billing lifecycle in one epic** — Checkout through automated delinquency/dormancy jobs.

## What we learned

- **Compressed bulk delivery 2026-07-22** — Stories 14.3–14.8 all done same day; 14.5–14.8 share baseline commit.
- **Thin story docs for 14.6–14.8** — No Review Findings vs full adversarial tables on 14.1–14.5.
- **Signup partial-failure paths accepted v1** — Non-transactional signup deferred with ops monitoring.
- **CAPTCHA off by default in compose** — Must enable before public launch.
- **Auth handoff via URL hash** — Post-verify checkout tokens in hash; deferred to one-time server code exchange.
