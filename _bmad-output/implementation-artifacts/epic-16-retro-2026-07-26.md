## What went well

- **Shared utilities reduced duplication** — `share-kit-utils.ts` and `ShareLinkPreview` kept activity and homepage share flows consistent (copy, preview, WhatsApp message shape).
- **UI polish bundled with feature work** — Activity detail shell cleanup (tabs, publish controls, registrations) made Share kit feel native rather than bolted on.
- **Adversarial code review caught real issues** — OG leak on draft/closed pages, Safari dual-download race, hero URL normalization, and partial-load failure UX were all fixed before merge.
- **Tenant URL resolution** — `resolvePublicSiteUrl` + door API lookup fixed the apex-localhost publish dialog showing bare `localhost:8088` instead of `creativorare.localhost:8088`.
- **Story docs stayed current** — Review findings tracked in story files with patch/defer/decision labels.

## What we learned

- **Client components must not import server modules** — `fetchPublicDoorClient` lived in `public-door-api.ts` alongside `fetchPublicDoorServer`, which pulled `next/headers` into the client bundle and broke the Next.js build. Fix: split into `public-door-client-api.ts` + shared `public-door-payload.ts`.
- **Merge conflicts on local pull often mean local drift** — Cloud fast-forward from `1c40f83` → `d72dca3` was clean; Francis's Windows conflict in `website-builder-page.tsx` came from uncommitted local edits, not upstream divergence.
- **Share pack downloads need stagger** — Browsers block simultaneous programmatic downloads; 400ms stagger in `downloadSharePackFiles` is required for QR + `.txt` pack.
- **Draft/archived share kit needs text-only unlock** — Disabled ghost buttons were confusing; text-only unlock messaging with clear publish-gate copy is the right pattern.
- **OG metadata must fail closed** — Non-indexable registration pages (draft, closed) must emit generic metadata, not rich activity OG tags.

## Key insights

1. **Share kit is high perceived value, low domain risk** — Validates PRD parking rationale: safe to ship early once tenant URLs and OG metadata are correct.
2. **Reuse beats parallel panels** — Deleting `ActivityQrPanel` and `ActivityHomepageFeaturePanel` in favor of one Share kit tab reduced navigation noise.
3. **Post-merge build verification is mandatory** — Rebase/import fixes (#13) and client/server split (#14) both surfaced only at build time, not in review alone.
4. **Checkpoint UAT before declaring done** — Publish URL, WhatsApp copy, and OG unfurl need operator eyes on real tenant hostname (`creativorare.localhost:8088`).
