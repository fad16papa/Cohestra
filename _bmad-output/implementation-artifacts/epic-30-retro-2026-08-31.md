## What went well

- **Story 30.10 as guardrail** — Dedicated invariant regression suite prevented Tally-style scope creep (caps, publish gate, theme separation) while 30.1–30.9 added surface area.
- **Incremental stack** — Each story merged into a branch chain; later stories (templates) built on close-at/meta without rewriting earlier work.
- **Adversarial review culture** — 30.6 reached **Pass 6 clean**; 30.8 Pass 3 clean; 30.9 Pass 4 clean; 30.11–30.12 through Pass 4. Email/piping stories benefited from repeated sanitization passes (pattern reused in Epic 32).
- **Plan gates at save time** — Basic blocked from scale/emergency/recipes; template slots monetized separately from registration caps (FR-RC-16).
- **Registrant-safe messaging** — Public API maps plan-limit conflicts to safe copy regardless of internal validator strings.
- **Hidden field privacy model** — Query passthrough without DOM render; extractor ignores hidden ids masquerading as PII fields.

## What we learned

- **Meta snapshot stories need cross-meta warnings** — Saving/applying templates copies full `form_schema.meta` including `registrationClosesAt`; past close-at can silently block the next event (deferred footgun).
- **GET vs POST availability should share one precedence function** — Close-at (30.8) introduced `RegistrationAvailabilityEvaluator` for submit; GET still composes flags in `ActivityService` — aligned today, drift risk tomorrow.
- **Template slot meter is sensitive to loading state** — 30.12 Pass 2 fixed race where Core/Pro tenants briefly saw Basic 0/1 meter; lesson: never default usage UI to Basic limits.
- **Multi-pass review finds email edge cases late** — Unicode line separators, `\r` in subjects, plain-text vs HTML sanitization — budget extra passes for operator-facing email builders.
- **Duplicated plan-gate helpers** — `EnsureFormSchemaPlanAllowedAsync` in both `ActivityService` and `FormTemplateService`; consolidate when adding the next Basic-locked type.
- **Epic 31/32 depended on 30.1** — Hidden query passthrough ported minimally into embed (32.2); full 30.1 editor still deferred.

## Team agreements

- **Capture never moves registration caps** — Template slots are the authoring SKU; 250/500/5000 stays sacred.
- **Hidden fields never render publicly** — Query passthrough only; preview chip in admin.
- **`registration_theme` stays out of `form_schema`** — Studio owns theme; templates snapshot fields + meta only.
- **Registrant-facing errors use safe copy** — Controllers map plan limits; no upgrade language on public POST.
- **Invariant story before monetization stories** — 30.10 landed before 30.11–30.12 template slots.
- **Multi-pass review for email surfaces** — Treat operator notify builders as security-sensitive.
