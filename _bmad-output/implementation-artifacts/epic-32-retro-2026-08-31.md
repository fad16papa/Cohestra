## What went well

- **Correct security layering** — Global `frame-ancestors 'none'` preserved; only `/embed/*` relaxes per-tenant origins. Admin and public `/register/*` unchanged.
- **Incremental epic stack** — 32.1 (CSP + settings) → 32.2 (embed UI) → 32.3 (contact) each built on prior work without rework.
- **Brownfield reuse** — `PublicRegistrationOpen`, `ClientDeduplicationService`, registration rate limiter, Settings section patterns, and Share kit extended rather than reinvented.
- **Adversarial code review discipline** — Especially on 32.3: email newline injection, plain-text truncation bug, flaky integration test, and Unicode line separators caught across passes 4–6 before clean sign-off.
- **Share kit operator UX** — Embed copy disabled when allow-list empty; bundled iframe + resize listener; campaign params documented on iframe `src`.
- **Contact without Registration** — Clear product boundary: website inquiry creates Client + timeline event, not a fake Activity registration.

## What we learned

- **Email builders need separate sanitizers for subject vs body fields** — Reusing subject-length caps (`SanitizeSubjectParticipant`) on plain-text body fields truncated name/email at 120 chars (pass 5 finding).
- **Plain-text email is a distinct attack surface from HTML** — `HtmlEncode` is not enough for operator notify plain-text bodies; need `CollapseInlineNewlines` including U+2028/U+2029.
- **Integration tests must set up their own preconditions** — `WithoutPublishedContactSection` was order-dependent until it explicitly published a hero-only site (pass 6).
- **Middleware CSP fetch needs server API base URL** — `next dev` double-CSP and wrong `API_URL` in embed middleware were real dev-environment footguns (32.1 pass 2).
- **Minimal 30.1 port is sufficient for embed but not for full form editor** — Hidden field editor UI still deferred to Story 30.1; embed path works via query passthrough.
- **Deferred e2e gap is intentional v1** — No automated `/embed/register` header or postMessage e2e tests; manual verify + unit tests accepted for launch.

## Team agreements

- **CSP relaxation is embed-route-only** — Never relax `frame-ancestors` globally.
- **Empty allow-list = no framing** — Share kit and CSP fail closed.
- **Contact creates Client, not Registration** — Do not route website inquiries through activity registration APIs.
- **Stack epic PRs in dependency order** — 32.1 → 32.2 → 32.3; do not merge 32.3 without its base chain.
- **Security-sensitive notify emails get multi-pass review** — Plain-text and subject sanitization are separate concerns.
- **Integration tests own their fixture state** — No assumptions about default tenant site configuration across test methods.
