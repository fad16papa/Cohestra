## What went well

- **Three-lane JWT claim model** — Identity `ClaimTypes.Role`, membership `"role"`, and `platform_admin` kept separate via `MapInboundClaims=false`.
- **Sequential spine on Epic 11** — Built on default tenant, role exclusivity, and platform lifecycle without re-implementing tenant entity.
- **Adversarial review captured in artifacts** — Each story has Review Findings with patch/defer/decision labels.
- **12.4 closed clean** — Re-review #2: no new actionable patches; ACs 1–4 met.

## What we learned

- **12.1 heaviest review cycle** — Bootstrap close timing, orphan-before-consume on refresh, register resume when bootstrap closed.
- **Dual-claim complexity** — Membership claim type vs ASP.NET inbound role mapping required explicit decision.
- **Integration HTTP matrix deferred** — Member→403, tenant JWT→403 on `/platform/*` deferred with unit/policy coverage as substitute.
- **Stubs stand in for Epic 14** — Team/Billing endpoints Admin-only placeholders until invite/Stripe work.
