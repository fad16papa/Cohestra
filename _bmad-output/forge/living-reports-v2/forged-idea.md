# Forged idea: Living Reports

## Locked

- Reports must **feel alive** before they feel exportable.
- Trust beats decoration: every insight must trace to the same query as CSV export.
- Prior-period comparison uses equal-length window immediately before current period start.
- Narrative is **rule-based** from metrics, not LLM-generated.
- Charts reuse dashboard visual language for consistency.

## Killed

- Hiding empty states behind charts — empty cohort gets honest guidance.
- Misleading +100% deltas when prior period is zero — show n/a instead.
- Separate "analytics product" navigation — Reports stays in operator workflow.

## Load-bearing metrics

| Metric | Operator meaning |
|--------|------------------|
| Registrations | Demand signal for the period |
| New leads | First-time people entering the CRM |
| Follow-up coverage | Are we acting on new sign-ups? |
| Repeat participants | Retention within filtered activities |
| Top activity | Where to double down next week |
