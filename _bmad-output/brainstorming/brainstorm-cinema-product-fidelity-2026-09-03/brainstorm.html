Technique · Reverse Brainstorming

How to guarantee cheap

Invent the failure factory — then invert every lever into the rescue kit.

How to fail

  • Keep chapter numbers — guarantees cheap
  • Add more checkmark pills — more brochure
  • More whitespace in mounts — more wireframe
  • Mint gradient hero — AI landing cliché
  • Invent a new mock design system — two products
  • Live tenant iframe — PII risk + lag
  • Dark mode cinema — fights paper-warm brand
  • Purple glow SaaS — AI-default aesthetic

Inverse rescue

  • Delete chapter chrome first
  • Delete checklist cards; write feeling lines
  • Fill whitespace with real admin chrome
  • Replace gradient with photography
  • One design system = real product components
  • Static DemoClub only, richer chrome
  • Stay light paper-warm with denser ink hierarchy
  • Cohestra tokens only — lagoon accents, no purple glow
