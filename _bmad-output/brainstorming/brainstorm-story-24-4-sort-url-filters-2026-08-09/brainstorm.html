Epic 24 · Story 24.4

Sort + URL-sync filters

Make the activities list bookmarkable, navigable, and sortable — the infrastructure layer before EXPERIENCE.md.

The gap today

24.1 synced status to the URL. Search, community, and category still live in React memory — refresh loses them, back button lies, links aren't shareable.

Backend always sorts UpdatedAt desc. No way to rank by name or registration volume.

Target URL

/activities?status=published&community=Northside&category=Fitness&search=tennis&sortBy=registrationCount&sortDirection=desc

Page stays local (like Clients). One bookmark = one operator view.

Sort options (v1)

Last updated default · desc
Created desc
Name asc
Registrations desc · ops gold

Data flow

Filter bar → router.replace URL → searchParams → fetchActivities → ActivityService sort + page

Explicitly out

  • Page in URL
  • Saved filter presets
  • Sort by schedule string
  • EXPERIENCE.md (→ 24.5)

Build Story 24.4

Mirror clients-list-page URL patterns + add server-side sort on four fields. Keep 24.1 recovery chips URL-native.
