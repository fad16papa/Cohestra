- (technique) started First Principles — mirror WhatsApp follow-up architecture
- (idea) API layer: ViberFollowUpRecorded enum + RecordViberFollowUpAsync mirroring WhatsApp line-for-line
- (idea) POST /api/v1/admin/clients/{id}/viber-follow-up with status contacted|awaiting_reply + optional note
- (idea) 15-minute duplicate cooldown on identical status+note — DuplicateViberFollowUpException → 409
- (idea) Reuse Normalize/Format helpers — extract shared follow-up status helpers or duplicate with Viber prefix for minimal diff
- (technique) started SCAMPER — UI placement options
- (idea) Option A: channel toggle on existing ClientOutreachLogCard (WhatsApp|Viber segmented control)
- (idea) Option B: duplicate Viber-only card — rejected (sidebar already Next follow-up + Log outreach only)
- (idea) Option C: auto-route save to channel of last initiated event — magic, hides intent
- (idea) Default channel toggle to most recent viber_initiated vs whatsapp_initiated timestamp
- (idea) Baseline dirty guard reads latest follow-up FOR SELECTED CHANNEL only
- (technique) started Failure Modes — dedup and UX edge cases
- (idea) Saving identical status+note within 15min shows API 409 toast — same as WhatsApp
- (idea) Switching channel mid-edit resets note but keeps status options shared
- (idea) Client with only Viber outreach still needs Viber tab default when no initiated events
- (idea) Timeline renders Viber follow-up with label Viber follow-up recorded + human status in subject
- (technique) started What If — multi-channel operator day
- (idea) Operator WhatsApps then Vibers same client — two independent follow-up logs, not merged
- (idea) Last outreach column on list must consider Viber follow-up in 21.3 — out of scope here but note dependency
- (idea) Post-save toast nudge Set follow-up date should fire for Viber saves same as WhatsApp
- (technique) started Constraint Flip — minimize scope
- (idea) No dashboard/report predicate changes in 21.2 — strictly profile + API + timeline
- (idea) No share-kit Viber copy — parked 21.4
- (idea) Integration tests: ViberFollowUpDedupIntegrationTests parallel to WhatsApp suite
- (idea) Unit tests: EnsureViberFollowUpIsNotDuplicate mirrors WhatsApp three cases
- (insight) Converged: channel-aware ClientOutreachLogCard + full WhatsApp mirror at API/service — smallest UX change, clearest operator intent
- (decision) Selected channel toggle on Log outreach card; default from latest initiated event; Viber accent on Viber tab only
