# Intent

Make Cohestra’s **activity form** Tally-fast to author without becoming Tally.

## Chosen directions

1. **Slash-add Form tab** (same types + textarea/date/hidden) — Tally muscle memory, still a list editor.
2. **Hidden fields / UTM** — kill the #1 reason to wrap a Cohestra page with Tally.
3. **Event recipes for show/hide** — guest, dietary, member — not a logic product.
4. **Optional 3-step** — identity, details, consent — default remains one page.
5. **Embed the activity** — later; highest Tally replacement, highest risk.
6. **Website contact → Client** — later; closes non-event leak.

## Critical discoveries

- Tally’s editor is **slash/type**, not drag-and-drop. Cohestra already banned DnD canvases. We can copy Tally’s *authoring feel* without violating UX-DR32.
- Tally free includes logic and Stripe. Competing on feature checklist is a trap. Compete on **person + event**.
- Epic 25 non-goals were about a **design** epic. Capture can be a **new** epic.
- Status-quo competitor is Tally+Sheets+Zapier, not Typeform.

## Do not take from this session

NPS, matrix, quiz scoring, CSS injection, formula checkout, “build a CRM in Notion.”
